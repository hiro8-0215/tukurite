# つくりて — おいしいが、作者に返る。

既存の「れしぴ棚」とは別のアプリ・別のデータベース・別のサイトです。既存アプリのコードやデータは変更していません。

## 実装した機能
- ChatGPTサインインとアカウント別の個人データ。
- レシピの公開・改訂・非公開化、料理写真のアップロード（JPEG/PNG/WebP、2MB以下）。
- 原本への参照を保つレシピ棚、検索、カテゴリー、保存順の並べ替え、手順チェック、調理報告。
- 固有URLの共有と取り込み。確認できない外部URLは出典付きの非公開メモに保存し、収益対象から除外。
- 外部投稿の確認コード発行。YouTube/TikTokの公開oEmbedタイトルにコードがある場合のみ照合。Instagram/X/Threadsは自動確認未対応のため未確認のまま扱う。
- 端末内AI（WebLLM / Qwen2.5 1.5B）による入力文章の材料・手順への整理。初回約1GB、WebGPU対応PCブラウザが必要。結果は要確認。
- 作者の収益試算、分配シミュレーター、Devnetテスト送金・試算額のテスト分配。
- ウォレットの期限付きメッセージ署名、レシピ本文のSHA-256記録、改訂履歴と保存内容の照合。
- サーバーでのSolana取引照合（署名者、Memo、送付先、金額）。未確定を成功扱いにしない。
- JSON書き出し、問題のある投稿の報告保存、スマホ表示。

## 分配の仕様
現時点では広告配信・サブスク課金・実売上・本番報酬は未接続です。月の仮分配枠0.001テストSOLを、保存1pt・調理報告3ptの比率で試算します。自己利用とサンプルは対象外。保存は1人1原本につき1回、調理報告は同一原本1日1回、合計1日10回まで。期間・日付の集計は日本時間です。

Devnet分配は資金提供者が接続したウォレットから明示的に実行するテストです。運営から自動で資金は供給されません。同月同作者の重複分配予約と仮分配枠を超えた予約はDB側でも防止します。分配試算は確定した債務・受取保証ではありません。

複数アカウント不正や、実際に調理した事実、真の著作者をチェーンが保証する仕組みではありません。投稿管理の確認も著作権認定ではありません。独自トークン・NFTは発行しません。

## 技術構成
Vinext / React / TypeScript / Cloudflare Workers / D1 / R2。ホスティングの既存認証を維持しています。秘密鍵はアプリに保存しません。チェーンはDevnet固定。料理本文・個人の調理報告はチェーンに送りません。写真は本文ハッシュに含みません。

DBスキーマはdb/schema.ts、マイグレーションはdrizzle/。GET /api/appは自分の個人データと公開原本を返し、POST /api/appは認証・同一Origin・所有者を検証して操作します。GET/POST /api/photoは画像保存とアクセス制御を行います。

## 開発
Node.js 22.13以上。依存導入は npm ci、型チェックは node node_modules/typescript/bin/tsc --noEmit、テストは node scripts/test-app.mjs、開発は npm run dev、ビルドは npm run build。

Windowsでnpm.cmdが誤った相対パスを使う場合は、インストール済みnpm-cli.jsをnodeで直接起動して、同じnpmスクリプトを実行してください。

D1のローカル検証では、一度ビルドしてから各drizzle SQLを順番に適用します：
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/<対象SQL>
適用済みマイグレーションは再適用しないでください。本番はSitesのデプロイ時に適用されます。

ローカル認証は/signin-with-chatgpt?return_to=/でテスト用Seedyとして開始。本番にはこの模擬認証を含めません。

## 検証
- 型チェックと公開用ビルド成功。
- 分離したSQLite環境のAPI統合テスト55項目に合格。署名は実際のEd25519鍵を生成して検証。RPC・外部SNSの照合はテスト応答を使って判定ロジックを検証しており、実ネットワーク確認と区別しています。
- ブラウザ：サインイン、原本公開、改訂履歴、保存、直リンク取り込み、外部の個人メモ、画像アップロード・配信、スマホ検索・横はみ出し、端末内AIの生成完了と生成結果の保存を確認。
- Devnet RPCの実通信は成功。使い捨てテスト鍵による給付は公開RPCの429/給付制限で停止。実際のMemo記録・送金の完了と、利用者のウォレット操作は未確認。
- 外部SNSの実投稿によるコード照合は未確認。投稿先へ勝手に確認コードを書き込む処理はありません。
