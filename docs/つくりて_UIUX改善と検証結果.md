# つくりて UI/UX改善と検証結果

実施日：2026-10-23。公開先：https://tsukurite-kitchen.expo.app/

## 改善した点

| 操作 | 問題と対応 |
|---|---|
| スマホ全体 | 小さく薄い文字を見直し、本文・補足のコントラストと入力欄の文字サイズを改善。主要ボタンを44px以上とし、下部ナビを固定。 |
| 見つける | 長い導入部分を短縮。検索入力時は導入を隠し、「鶏肉 トマト」のような複数語で絞り込めるようにした。全角英数字にも対応。新しい順の並び替えを明示的に実装。 |
| 保存・調理 | 保存済みの状態をボタンにも表示。報告済みの日は調理報告を重複して押せないようにした。外部の非公開メモにも手順チェックを追加。 |
| 自作の発信 | 入力を端末へ自動保存し、再読み込み後も復元。新規下書きと各原本の改訂下書きを分けた。未入力、0人分、不正な調理時間では公開を止め、必要な項目を表示。 |
| AI編集 | メモ→AIの案→確認・反映→公開の流れをガイド。変更後は公開への同意を取り直す。入力は反映を選ぶまで変えない。 |
| 外部からの取り込み | 画像添付の下にAI抽出ボタンを配置。添付枚数・取り外しを表示。画像読込中や抽出中は入力操作を止め、古い入力による上書きを防ぐ。保存前に出典URLを確認。 |
| ログイン・設定 | ログインと新規登録を選べる表示、ID形式の案内、パスワード表示切替を追加。画面に常駐していたログアウトをプロフィール内へ移した。認証期限切れ時の再ログイン導線も修正。 |
| アクセシビリティ | モーダルを開くと背後の操作を無効化し、キーボードのフォーカスを閉じ込め、閉じると元の位置へ戻す。状態通知・手順チェックの選択状態・動きを抑える設定にも対応。 |
| 通信失敗 | 写真の読み込み失敗を表示。共有リンクのコピーに失敗した場合は手動コピー用の欄を表示。 |

## 検証結果

- 本番ビルド・TypeScriptチェック・差分の空白チェック：成功。
- `scripts/test-experience.mjs`：21項目成功。複数食材の検索、全角文字、並べ替え、入力制限、アカウントと原本ごとの下書き分離、壊れたデータ・保存領域の失敗を確認。
- `scripts/test-live.mjs`：39項目成功。認証、保存、公開と非公開、取り込み、写真の閲覧権限、署名検証、データへの直接アクセスの拒否など。Geminiの実テキスト抽出も200で成功。
- ブラウザー実操作：ログイン、食材を組み合わせた検索、保存済み表示、棚の検索結果0件からの復帰、下書きを閉じて再読み込みしてからの復元、Geminiによる案の生成、反映前に入力を保持、反映後の公開同意、0人分の公開防止を確認。
- 外部メモ：不正なURLの保存防止、非公開での保存、メモの表示、調理手順チェックを確認。
- 画像：テスト画像の添付枚数表示、取り外し、取り外した後の空の抽出ボタン無効化を確認。
- 表示：通常の内蔵ブラウザーに加え、プレビュー専用iframeで320pxと1366pxの画面をレンダリング。320pxで横はみ出しなし、編集モーダルも横はみ出しなし。1366pxで3列のレシピカードとサイドバーを確認。
- ログアウト：プロフィールから実行し、ログイン画面へ戻ることを確認。

## 保存範囲と今回の対象外

下書きは、同じ端末・ブラウザー・アカウントで復元するものです。別のスマホへの同期はありません。共用端末では下書きが残る点を画面にも表示しています。公開すると、その下書きだけを削除します。

元のレシピ棚、Supabase・Expo・Gemini Flashの基盤、無料枠の回数保護は維持しました。今回、Solanaの送金・メインネット操作や、広告・課金の接続は行っていません。ウォレットなしで基本操作ができます。

認証期限切れ、写真の通信失敗、クリップボード拒否時の分岐はソースとビルドで確認していますが、ブラウザーでそれぞれの障害を強制発生させる試験は行っていません。320pxと1366pxの確認は実機端末のOSやウォレットの相性試験を代替するものではありません。
